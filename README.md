# Weather App

Небольшое погодное приложение, которое показывает текущую погоду для местоположения пользователя.

В работе я собрал простой интерфейс с температурой и дополнительными показателями, предусмотрел обновление данных и сообщения об ошибках. Проект стал практикой работы с данными и состояниями интерфейса.
